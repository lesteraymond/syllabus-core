# Stage E.1 - design notes

**Title policy** (`titles.js`, `SYLLABUS_CHECK_TITLE_POLICY` = `shadow` (default) | `exact` | `normalized`). Normalisation: Unicode NFKC, zero-width characters removed, case folded, whitespace collapsed. Punctuation, digits, words and parentheses stay significant; no fuzzy matching. Relations: `exact`, `case_or_space` (match), `subtitle` (the approved title adds a parenthetical; not a match), `different`, `missing`. In `shadow` the official check stays exact; `hybrid.shadowCurriculum` reports the alternative and its impact; `normalized` needs your approval. Impact on the existing and sample syllabi: `docs/title-normalization-impact.md`.

**Partial validation** (`identity.js`, `hybrid.identity`). Statuses: `verified`, `code_missing`, `code_not_found`, `curriculum_unavailable`, `curriculum_ambiguous`; `elsewhere` lists other approved curricula that contain the code (information only, never a match). A wrong code still zeroes the official score and fails curriculum. All deterministic checks (fields, four CLOs, 18 weeks, placeholders, grading, structure) already run and are reported; the AI stays off as before unless `SYLLABUS_CHECK_PROVISIONAL_AI=on` (default off), in which case findings are labelled provisional, no alignment points reach the official result, and the verdict cannot be COMPLIANT.

**Values classification** (`valueClassification.js`, D1 flag). Faculty text is never changed; a derived record per lesson (`hybrid.valuesClassification`: `canonicalCoreValue`, `supportingValue`, `competency`, `integrationEvidence`, `classificationStatus`) is built from a proposed vocabulary (`server/config/values-lexicon.json`) and, where lesson evidence exists, the advisory `Value-map` question (VAL-05). No fixed mapping from a supporting value to a core value exists. The existing data model (free text in `plan[i].values`) is enough: no migration. A structured builder field is backlog.

**Separate results** (`verdict.states`): identity, structure, curriculum, academic alignment, institutional values, and references split into format / relevance / authenticity.

**Backlog (not started):** activity-to-assessment consistency; per-week reference relevance; a structured values field in the builder; the blind default value suggestion in the coded VALUE check (it proposes "Compassion" when nothing else matches) should be reviewed with the institution.
