- **Is:** a real Edge/Chromium browser driving the real React production build over https, through a TLS reverse proxy, to the real Express server running as `NODE_ENV=staging` (Secure cookies, explicit CORS origin, trusted proxy, fail-closed secrets), against a scratch MySQL database built from `init.js` plus every migration and filled with synthetic data only.
