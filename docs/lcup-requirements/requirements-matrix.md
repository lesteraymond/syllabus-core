# Consolidated requirements matrix

This is one matrix for the original requirements. “Code before → after” distinguishes availability from execution. IMPLEMENTED means an executable path exists; DISABLED means the semantic path exists but the inspected configuration does not activate it; PARTIAL identifies a stated scope limit; MISSING means no responsible implementation was found. “Claude” means the configured production provider, not an offline oracle. No live semantic judgment was requested.

Configuration evidence: [environment.json](environment.json), read from `server/.env` without changing it or exporting secrets. Every existing optional academic flag is unset/off. Anthropic is selected, but the application-approved model setting is absent, so `providerConfig` returns `configured:false`. AI gate defaults to advisory. This describes the repository's local launch configuration, not a separately observed deployed process or external environment override.
