# Original requirements → executable Policy V2

Policy: `academic-evaluation-v2-preview-1`. Code is implemented; execution is **offline opt-in only**. Every row below is inactive in the normal production checking path unless it was already part of legacy behavior. A successful mocked test establishes software behavior, not Claude accuracy or faculty agreement. No new academic points or thresholds exist.

Backend paths below are relative to `server/lib/syllabuscheck/`. `plan` means `academicV2Plan.plan`; `evaluate` means `academicPolicyV2.evaluate`. The ordinary shared service and engine select this version explicitly; they do not run the legacy penalty loop first.
